# Portafolio de Matías Orellana
 
¡Hola! Este repositorio reúne mis proyectos de análisis de datos, desarrollados como parte de mi formación y práctica como Ingeniero/Analista de Datos.
 
Cada carpeta corresponde a un proyecto independiente, enfocado en distintas etapas del trabajo con datos: desde la exploración y limpieza, hasta la visualización, el modelamiento estadístico y la aplicación de técnicas cuantitativas para responder preguntas concretas.
 
El objetivo de este portafolio es mostrar de forma ordenada mi forma de trabajar con datos: cómo exploro, interpreto y comunico resultados usando herramientas como Python y R.
 
## Proyectos
 
| Proyecto | Descripción |
|---|---|
| [Análisis exploratorio de datos](./Analisis-exploratorio-de-datos) | Exploración y limpieza de datos como base para el análisis. |
| [Criminalidad en Londres](./Criminalidad-en-londres) | Análisis de datos de criminalidad aplicando herramientas de análisis exploratorio. |
| [Matplotlib y Seaborn](./Matplotlib-y-Seaborn) | Visualización de datos utilizando librerías de Python. |
| [Movilidad laboral](./Movilidad-laboral) | Estudio de patrones de movilidad laboral. |
| [Proyecto econométrico](./Proyecto-econometrico) | Aplicación de modelos econométricos en R. |
| [Clusters con R](./Clusters-con-R) | Segmentación de datos mediante técnicas de clustering en R. |
